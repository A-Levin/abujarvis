# Abu Jarvis

Менеджер долгоживущих табов Claude Code. Публичный проект (MIT).

## Док живой — главное правило

**Любое изменение кода = правка README в том же коммите.** Не «потом», не «в конце этапа».
Раздел «Состояние» обязан отражать факт, а не намерение.

Два README, оба — настоящие файлы в репо: `README.md` (английский, основной) и
`README.ru.md` (русский). **Меняешь один — меняй оба**, они не должны разъезжаться.
Личная заметка в Obsidian-хранилище — симлинк на `README.ru.md` (симлинк снаружи внутрь, не наоборот).

Симлинков внутрь репо быть не должно: проект публичный, при клонировании они ломаются.

## Проект публичный

- Код, CLI-вывод, README, роль в `templates/role.md` — **по-английски**.
- Общение с хозяином репо — по-русски.
- Никаких захардкоженных домашних путей, личных данных и токенов в коде.
  Всё через `os.path.expanduser` и переменные `ABUJARVIS_HOME` / `ABUJARVIS_SESSION`.
- `.omc/` и прочий мусор плагинов — в `.gitignore`. Он уже утекал в историю; проверяй
  `git ls-files` перед пушем.

## Устройство

- `abujarvis` — CLI (python3, без зависимостей). Ставится в `~/.local/bin` как `abujarvis` и `aj`.
- `hook.py` — все четыре хука (SessionStart, UserPromptSubmit, PreCompact, Stop).
- `install.sh` — симлинки, роль, регистрация хуков (с бэкапом settings.json).
- `templates/role.md` — роль менеджера, копируется в `~/.abujarvis/CLAUDE.md` при установке.
- Состояние: `~/.abujarvis/` (вне репо).

## Правила кода

- Код без комментариев.
- **Хуки обязаны быть быстрыми и никогда не падать**: любая ошибка → `exit 0`.
  Иначе ломается таб, в котором человек работает. Это не стиль, это требование.
- Не выдумывать интерфейсы Claude Code — проверять эмпирически.
  (`~/.claude/daemon/roster.json`, например, не существует, хотя доки-агент его «помнил».)
- Не перебивать табы: задачи только через очередь, никаких `tmux send-keys` в живой агент.
